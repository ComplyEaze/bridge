- The `open_bills` detail of `outstandings` now reads a party whose name holds marks, in the shapes the lab has read through Tally's `Ledger Outstandings` report: the marks `-` `.` `&` `/` `(` `)` `'` `,` `_` `"` `+` `@` `#` `:` `%` `*` `!`, each only between the neighbours a kept capture shows it between; the word `and` in lower case, only between two other words; and the Devanagari word उदाहरण, whole and not first. Such a name must start with a letter and be at most 72 characters, the longest such name read. Before, it refused any name outside ASCII letters, digits and single spaces, which are still read as before. Such a name is read only when no other ledger of the company, by name or alias, has the same letters and digits; otherwise it is refused as `party_name_not_admitted` with cause `party_name_key_shared`. Any other character is refused with cause `party_name_mark_not_measured`, a measured mark or character in an unread place with `party_name_position_not_measured`, any other formula word (`or`, `not` and the rest, or `and` elsewhere or in another case) with `party_name_formula_word_not_measured`, a longer marked name with `party_name_marked_too_long`, and a space at an edge or doubled with `party_name_spacing`, all before anything is sent, each with its own next step.
