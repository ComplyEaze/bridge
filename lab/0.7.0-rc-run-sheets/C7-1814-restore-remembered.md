Simulator only so far.

A bank ledger (Lab Bank) and one party ledger under Sundry Debtors; Receipt voucher type Automatic numbering with "retain existing numbers" on; no voucher on the chosen day D. RUN ONLY ON THE RELEASE-CANDIDATE BUILD. Never open this data folder with an older build afterwards: an older release refuses a journal holding the new record and stops builds, posts and verifications (the changelog says so).
