- The party/ledger master workbook now shows the mailing details for a book with many master alterations but few ledgers. For a book whose master-alteration mark is past 4,266, ComplyEaze Bridge already counts the ledgers before reading them. Where the counted ledgers fit the read's estimated bound, each allowed four further mailing entries the mark may not show (one save in Tally can add several) and one more for each alteration beyond them, the workbook now asks for the mailing details instead of leaving those columns not observed. This is an allowance (unverified), not a bound: it rests on one lab book. Such a book, with a mark from 4,267 to about 13,300 and up to about 1,265 ledgers, used to be read without the mailing details and is now sent the larger request. **A book that exported before still exports, unless Tally may still be working on the larger read.** That is where the larger read runs out of time, or runs past the size limit without Tally saying so at the start of its answer: the export then fails, and its error says the mailing addresses were part of the failed read; only after the size limit does it add that the size estimate may have been too low. After any other failure of the larger read, the export reads the book once more with the standard request and writes the workbook without the mailing details, with a note in its header that says how the larger read failed (#2214). Where that answer broke off, could not be read, or never came, Tally may still be sending it, so the export first waits up to 60 seconds while Tally is still busy with that read (a bound not measured), and fails, saying so, if Tally is still busy after it. An answer that did not decode is read again at once, since no wait follows it (#2142). The read once more makes every check the export made before this change. This fallback has not been run against Tally: only Tally's answer past the size limit, and a separate read straight after it, were seen in the lab. A book of more ledgers, or with more alterations than fit, is read as before. A book whose mark is from 3,201 to 4,266 is not counted, so it is still read without them (part of #2074).
