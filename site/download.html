Before you install

  • ComplyEaze Bridge is still being developed and may contain errors. Try it first on a test company, and take a backup before you turn posting on.
  • Posting is off by default in a new install. If you upgraded from an earlier version, check the setting. There is no tool to undo or delete a posted voucher; you correct it in Tally. A post can still land in a company renamed after the last check, and a replaced ledger is not always noticed; the README gives these limits in full.
  • Each download has a matching .sha256 file on the same release. Compare it with your download before opening the package.
  • What has been run against a real TallyPrime, and what has not, is listed in the README.
  • Tally must be running on the same computer as Claude Desktop.
  • You bring TallyPrime and Claude Desktop, and what Claude reads goes to Anthropic. ComplyEaze Bridge has no account and no price set today.
  • On a Mac, run Tally in a Windows virtual machine on that same Mac with its gateway port forwarded to the Mac's localhost, or reach it through local port forwarding your organisation has approved. ComplyEaze Bridge talks to Tally only on localhost, so a separate PC, or a Tally elsewhere on your network, cannot be reached.

Install, once

  1. In TallyPrime, turn on the HTTP gateway (Tally acts as “Both”).
  2. Open the downloaded .mcpb file. If Claude Desktop doesn’t pick it up: Settings → Extensions → Advanced settings → Install Extension. Claude Desktop may note that the extension is not verified by Anthropic.
  3. Check the Tally port in the extension settings (usually 9000).
  4. Read the Terms of Use linked in the extension settings, then turn on “I accept the ComplyEaze Bridge Terms of Use”. Until you do, every tool refuses and the assistant tells you why.
  5. Save the settings, then quit Claude Desktop completely and reopen it. Then ask about your books in plain language.
