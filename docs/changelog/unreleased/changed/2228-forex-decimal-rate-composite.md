- On a TallyPrime 7.2 book, a foreign-currency balance written with a rate that has decimals is now set aside by name, like one with a whole rate, instead of refusing the read. Tally can write such a rate even when every rate keyed was a whole number. This applies to `ledger_masters` with the compliance fields and the other reads that classify ledgers the same way, including the ledger snapshot `outstandings` reads. The balance's value is never read (#2228).
