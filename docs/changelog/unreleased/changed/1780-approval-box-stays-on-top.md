- On Windows, the box that asks a person to approve a post, to record a review or to release an invoice stop is now opened so that it stays above Tally when the person clicks into Tally while it is open. When the box opened a few seconds after the person's last input to Tally, Windows had not kept it on top, and one click into a maximised Tally covered it until it was brought back from the taskbar. Staying on top does not take the keyboard: after such a click, keys go to Tally. The box that asks to create a ledger is not covered by this change (part of #1780).
