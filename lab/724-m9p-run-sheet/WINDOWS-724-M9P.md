## What it decides
- Whether, with duplicates prevented, a Payment is refused for a number another Payment holds (p2, after the control p1).
- Whether a Journal is refused for a number that only a Payment holds (p3): with 724-M9O's o3, whether the check runs within each type in both directions.
- Whether a number in small letters is refused in itself when nothing holds a twin of it (p4): this decides how 724-M9O's refusal of "m9o-a1" may be read.
- What the voucher read returns for a number that ends in a space (p5), and whether the same number without the space is then refused (p6).
