- On a Mac, every approval window (the post, the review, the invoice-stop release, the batch settlement and the ledger create) is now measured before it opens. The macOS window has no scroll and opens at a fixed height on the screen, so a long text could leave its buttons below the bottom of the screen. ComplyEaze Bridge now lays the text out as the window does, and refuses one that would run past the bottom of any of the Mac's screens. A batch whose list of vouchers is too long is refused once and shows its totals when asked again, as on Windows. A single voucher, review, release or ledger whose window would not fit is refused. A larger or less magnified display, or moving the Dock to the side or hiding it, gives the window more room. On a small screen set to a larger text size, even the shortest voucher can be refused. The window's measurements come from one Mac and one macOS version, and where it opens when there is more than one display is not measured, so the window must fit on every screen (part of #1780).
