## What it decides
- Whether, with duplicates prevented, a number held only by a Journal blocks a Payment that carries it (o3, read against the two controls o1 and o2).
- Whether a number that differs from a held one only in letter case is refused, and how it is stored if it is created (o4).
- Whether "01" is refused where "1" is held, and how it is stored if it is created (o5).
- Whether a back-dated Journal with a new number is kept (o6), and whether a numbered Payment is accepted raw on this book at all (o2).
- Whether either type's series row records anything after each (the SERIES reads).
Not covered: a small-letter number, or a number with a leading zero, that has NO held twin (so a refusal at o4 or o5 is not proof of a match); the other direction (a Journal whose number only a Payment holds); Receipt and Contra; a number with spaces; a number differing in case from one Tally assigned itself; duplicates prevented under "Automatic (Manual Override)"; a file of several vouchers; Multi-user Auto; a deletion; Gold; other releases; the same through ComplyEaze Bridge's own post.
