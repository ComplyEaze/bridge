At a glance, release 0.7.0

  • You can ask: outstanding receivables and payables, with ageing of the open bills; the trial balance for a period; the vouchers in a date range, found by number, reference, narration or amount and added up by ledger, month, voucher type, group or primary group (checked on one synthetic book, not a large one); Tally’s own Cash Flow for whole months, shown only when its net total ties to the trial balance (not a cash flow statement under AS 3; tried on two synthetic books); one ledger’s opening, debits, credits and closing; Tally’s own month-wise Sales or Purchase Register for whole months (not tied to the vouchers; read on one synthetic book); Tally’s own Negative Stock and Negative Ledgers lists for a window (being listed is not a finding; synthetic books only); and the vouchers of one type that Tally marks Uncertain in its GSTR-1 (a Sales type, measured on one synthetic book).
  • Partly, with limits: profit and loss and the balance sheet, which on a book with stock items are read only when Tally’s own closing stock closes every gap (one synthetic book measured) and which a book with several currencies does refuse; closing stock value per item at a month’s last day and its closing quantity (compared with Tally’s own Stock Summary for an item on a line of its own, the item list’s own for an item inside a stock group), on small books only, checked on two lab books; and a password-protected SBI, HDFC, Union Bank of India or Bank of Baroda PDF statement, read into a file of Payment, Receipt and Contra vouchers that you check and import in Tally yourself. It creates no ledger, it cannot build onto a Cash-in-Hand ledger, a line it cannot place goes to a suspense ledger you name, and it has not yet been run on a real bank statement.
  • Not in release 0.7.0: GST returns or GSTR-2B matching; making sales or purchase invoices or GST entries; tax-audit flags (one test, the cash share of receipts and payments against the s.44AB(a) limit, is off by default and not yet run against a live TallyPrime); Tally’s Funds Flow and Ratio Analysis reports.
  • “You can ask” means it answered on the books and builds we ran it on, which the README lists (not every read has its own recorded run); the program in the published Windows 0.7.0 file has had one read-only run against TallyPrime 7.2 Silver, on one Windows computer and one synthetic company on 30 October 2026, started by our test client, not from Claude Desktop; it read Tally’s status, listed the companies and read the ledger masters; nothing was posted; the Mac file has not been run against TallyPrime. Very large books can fail or take longer than the assistant waits, and a book with several currencies is read only in part. Check any figure you rely on against Tally. Before you install

  • ComplyEaze Bridge is still being developed and may contain errors. Try it first on a test company, and take a backup before you turn posting on.
  • Posting is off by default in a new install. If you already have an older release installed, it may keep its own settings, posting included: read If you already have an older release below before you install. There is no tool to undo or delete a posted voucher; you correct it in Tally. A post can still land in a company renamed after the last check, and a replaced ledger is not always noticed. The approval window for a post covers only ComplyEaze Bridge: another Tally connector in the same Claude Desktop that can change entries can do so without it. The README gives these limits in full.
  • Each download has a matching .sha256 file on the same release, linked under its button. Compare it with your download before opening the package: on Windows, in Command Prompt, type cd Downloads and then run certutil -hashfile "<file>" SHA256; on a Mac, in Terminal, type cd Downloads and then run shasum -a 256 "<file>" (put your downloaded file’s name in place of <file>, brackets included, and keep the quotes: a file downloaded twice can get a name with “(1)” in it, which needs them). Check that the 64-character code it prints matches the code at the start of the .sha256 file (open that file in Notepad or TextEdit). This check shows the file arrived whole; it does not show who made it.
  • ComplyEaze Bridge does not update itself. Look for a newer version on the releases page on GitHub: its name starts with “ComplyEaze Bridge MCP”.
  • Tally must be running on the same computer as Claude Desktop.
  • On Windows, ComplyEaze Bridge also needs Microsoft’s Visual C++ Redistributable (x64). Many programs install it, so you may already have it; if you do not, or are not sure, the installation guide has Microsoft’s download link, and you install it before you add ComplyEaze Bridge to Claude Desktop.
  • You bring TallyPrime and Claude Desktop, and what Claude reads goes to Anthropic. ComplyEaze Bridge has no account and no price set today.
  • On a Mac, run Tally in a Windows virtual machine on that same Mac with its gateway port forwarded to the Mac's localhost, or reach it through local port forwarding your organisation has approved. ComplyEaze Bridge talks to Tally only on localhost, so a separate PC, or a Tally elsewhere on your network, cannot be reached.

Install, once

Already have ComplyEaze Bridge installed? Read If you already have an older release first.

  1. In TallyPrime, press F1, then Settings, then Connectivity, then Client/Server configuration. Set “TallyPrime acts as” to Both, note the Port number (usually 9000), save, then close and reopen TallyPrime.
  2. In Claude Desktop, open Settings, then Extensions, then Advanced settings, and click Install Extension. Choose the downloaded .mcpb file. In our test, Claude Desktop showed its own notice that the extension is not verified by Anthropic, then asked us to confirm.
  3. Read the Terms of Use linked in the settings that open (if none open, open Settings, then Extensions, then ComplyEaze Bridge), then tick “I accept the ComplyEaze Bridge Terms of Use”. Until you do, ComplyEaze Bridge does not read from Tally, and from release 0.5.1 every tool answers that the Terms of Use are not accepted and names this setting (the tools the assistant called gave that answer on one Mac with a test package and on one Windows computer with the build our checks made for this release). (In 0.5.0, after an update from 0.4.2, Claude Desktop may not start it: on a Mac with an error that does not mention the Terms, on one Windows computer with no error.)
  4. Type your Tally port (usually 9000). Leave the Tally host as localhost and leave posting off until you have tried ComplyEaze Bridge on a test company.
  5. Click Save, then quit Claude Desktop completely and open it again. Ask “Which company is open in Tally?” Claude Desktop may ask your permission before it uses a tool; in our test we chose Allow once.

First time, or on a Mac? Start with a test company. The installation guide has every click, what each screen shows, and what to do when yours differs.

If you already have an older release

  • Over 0.4.2 or 0.5.0, an install replaced the older release as an update, on one Mac and with builds that were not the published files: a build of 0.5.0 made by our checks kept the Tally port, Response redaction and posting setting of 0.4.2, and a test package of 0.5.1 was installed over 0.5.0 as an update. Check the Terms of Use setting after you install.
  • Installing over 0.5.1, 0.6.0 or 0.6.1 has not been measured. Take a backup of ComplyEaze Bridge’s data folder first, then install the new file over it.
  • The posting setting has had its present name since 0.6.0, so a posting setting turned on in 0.6.0 or 0.6.1 may still be on after an update; one from 0.5.1 or earlier does not carry over, and posting starts off. Check it after you install, and leave it off until you have tried ComplyEaze Bridge on a test company.
  • Once 0.7.0 has recorded a person’s check or settlement of a post (acknowledge_post_review), do not go back to 0.6.1: an older build refuses the whole import journal once such a record is written.
  • Installing over a release older than 0.4.2 was not tried: remove such a release first, keep its data folder, and enter your settings in the new one, including Response redaction, which starts at none. If Settings → Extensions lists two ComplyEaze Bridge entries, remove the older entry before you use either, then tick the Terms setting and quit and reopen Claude Desktop (steps 3 to 5 of “Install, once” above).
