- The by-hand check `node scripts/release-text-agreement.mjs --published mcp-vX.Y.Z` now compares the tag with the release GitHub marks latest, read from `/releases/latest`, instead of the release with the greatest publication time. An older line that receives a later patch, or a marker set by hand, no longer makes the check approve text that disagrees with the release GitHub presents as latest. A latest answer that cannot be requested or read is still a typed refusal (#2552).
