- On a Mac, every approval window (the post, the review, the invoice-stop release, the batch settlement and the ledger create) is now measured before it opens. The macOS window has no scroll and opens at a fixed height on the screen, so a long text could leave its buttons below the bottom of the screen. ComplyEaze Bridge now lays the text out as the window does and refuses one that would run past the bottom of the screen. A batch whose list of vouchers is too long is refused once and shows its totals when asked again, as on Windows. A single voucher, release or ledger whose text is too long is refused, and the message says how to post it anyway: build it again with a shorter narration, post a batch in smaller parts, or approve it in ComplyEaze Bridge on a Windows PC. The window's measurements come from one Mac and one macOS version, and where it opens on other screen sizes is not yet measured, so the check takes the lowest of the possible positions (part of #1780).
