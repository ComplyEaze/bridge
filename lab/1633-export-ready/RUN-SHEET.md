## Why this sheet exists
#1633 asks whether a GSTR-1 export moves the company's voucher mark `ALTVCHID` and whether the next voucher then skips that rise, because a native post is checked against the marks before and after it. An earlier capture on TallyPrime 7.1 (work order W13) measured the voucher mark rising by 3 across each JSON export of the August Sales window (what took the three ids was not identified). On 28 Oct 2026, `lab/1633-span-mark-answers` ran the question on 7.2 and could not answer it: the only Sales voucher in the book had no HSN/SAC, so GSTR-1 counted it as uncertain, April showed nothing pending to upload, and the choice on key X that exports to a file did nothing; the reads taken after it equalled the reads taken before it.

This sheet gives the book a Sales voucher the return can take, then exports, then keys one more voucher. Nothing else about the question changes.
