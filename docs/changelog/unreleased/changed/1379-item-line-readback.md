- A posted Sales invoice whose ledger entry holds a stock item in Tally now reads back as `posted_divergent`, never `posted_verified`. Its `diffs` name the item line with `invoice_line_item_not_sent`, `invoice_line_items_several`, `invoice_line_item_differs` or `invoice_line_item_batch`. The HSN/SAC check of that line reads the code Tally filled on the item line. Before, the read-back did not parse the item, and such an invoice could read as verified on the entry alone (#1379).
