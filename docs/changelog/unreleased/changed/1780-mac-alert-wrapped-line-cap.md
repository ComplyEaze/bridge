- On a Mac, every approval window (the post, the review, the invoice-stop release, the batch settlement and the ledger create) is now refused before it opens when its text would be longer than the window can show whole on a 13-inch screen. The macOS window wraps each line itself and has no scroll, so a long text could leave its buttons off the screen. The check counts lines as the window wraps them, not as they are written. A batch whose list of vouchers is too long for it is refused once and shows its totals when asked again, as on Windows. A single voucher, release or ledger whose text is too long is refused on a Mac where it was shown before, and the message says how to post it: build it again with a shorter narration, post a batch in smaller parts, or approve it in ComplyEaze Bridge on a Windows PC, whose window is unchanged. The window's size on a Mac has not yet been measured, so the limit is an estimate until the macOS lab row measures it (part of #1780).
