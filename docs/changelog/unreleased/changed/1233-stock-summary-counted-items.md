- `stock_summary` now reads a book whose master-alteration mark is past 874, as long as it holds at most 874 stock items. Before, any such book was refused. ComplyEaze Bridge first counts the stock items and stock groups by AlterID span, then reads the items in one request and sizes the Stock Summary report from the counts before reading it. A book with more items is still refused as `stock_summary_too_large`, and its `size` now carries `counted_items` and `limit_items`. A count that cannot be made refuses as `stock_summary_census_refused`, a report too large as `stock_summary_report_too_large`, and a Tally item count above the census's as `stock_summary_item_count_company_higher` (part of #1233).
