## Findings, word for word
- **Renumbering.** The import sent VOUCHERNUMBER `5` (`I-5-sent.xml`, REMOTEID tail 0805). Tally answered CREATED 1, LASTVCHID 4, every other counter 0, no LINEERROR. The voucher stored is MASTERID 4, GUID `<the book's GUID>-00000004`, VOUCHERNUMBER `3`, Sales, 20250403. The Sales voucher type numbers automatically (`Automatic`, `Auto Retain`), so Tally gave the next number in place of the one sent. Row 2162-IRN9's invoices `3` and `4` were sent with the next numbers, so that row could not show this.
- **Ledger accept.** Ctrl+A on the IGST ledger's alteration screen saved it with no `Accept ?` prompt.
- **Report refresh.** Opening the e-Invoice report after a GST master change showed the dialog `GST-related details were altered in the masters/Return. Hence, opening the report will update the GST Status of 2 vouchers. Do you want to open the report? Yes or No`, which updates voucher status. Neither mark moved.
