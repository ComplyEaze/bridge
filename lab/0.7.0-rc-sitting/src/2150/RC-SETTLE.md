Not for merge. `LAB-COMMON.md` (v3, the byte copy in this folder, sha256 in `SHA256.txt`) applies in full; where this row and it differ, the stricter holds, except where this row says it widens a LAB-COMMON rule (the whole-book restore after a STOP, the one Escape that leaves the List of Masters popup, and the lock screen's own accept in step 2.1), and except the substitutions it names: the build's tools for C3's raw requests, `list_companies` for C3's one-COMPANY check before the write in step 4, and keys on Tally's own screens in the steps KEYS lists. Part 1 posts a qualified Journal natively into a locked period. Part 2 runs only if Part 1 gives no whole refusal.
