- The party/ledger master workbook now shows the mailing details for a book with many master alterations but few ledgers. For a book whose master-alteration mark is past 4,266, Bridge already counts the ledgers before reading them. Where the counted ledgers fit the read's estimated bound, each allowed four further mailing entries the mark may not show (one save in Tally can add several) and one more for each alteration beyond them, the workbook now asks for the mailing details instead of leaving those columns not observed. No further request is sent to Tally, though the answer is larger; if that larger read fails, the export's error says the mailing addresses were part of it. A book of more ledgers, or with more alterations than fit, is read as before. A book whose mark is from 3,201 to 4,266 is not counted, so it is still read without them. The size estimates this relies on are not measured on such books (part of #2074).
