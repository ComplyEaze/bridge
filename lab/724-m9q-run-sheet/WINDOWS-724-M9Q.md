- Whether a raw VOUCHERTYPE Create under Journal gives a series numbered Manual with duplicate numbers prevented, with the type-level elements only (q1) or with a series list (q2).
- Whether a number held in the parent Journal type blocks its child (q4), and a number held in the child blocks the parent (q6). - What a Create on a name that already exists does (q8).
