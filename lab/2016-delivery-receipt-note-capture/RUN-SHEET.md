This sheet WRITES: two voucher types are made active (a recorded setting change) and two vouchers are keyed by hand on Tally's screens, then the book is restored from a backup; ComplyEaze Bridge only reads. `SHA256.txt` lists every file here with its bytes; check it before step 0.

## What it decides
The first #2016 row (`lab/2016-stock-movement-capture-answers`) read a Stock Journal and a Credit Note on this book, but could not key a Delivery Note or a Receipt Note: both are inactive voucher types here (Show Inactive lists them greyed). Delivery Notes and Receipt Notes are expected to carry stock with no accounting entry, so the shipped vouchers request may return them with an empty ledger list or not at all. This sheet makes the two types active, keys one of each, and records what the shipped request (a07) and the inventory fetch (a08) return for each, how direction, godown and batch are marked, and how the Stock Summary for the month moves, against Tally's screens. It decides no read, tool name or estimate for #2016.
