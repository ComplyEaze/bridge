# W26: where Tally keeps a Sales credit note's original invoice number and date: its whole voucher object, read twice, once keyed with the two values and once without

Synthetic company `BRIDGE PILOT LAB` only. It WRITES: one Credit Note keyed on screen, then the book restored from a backup taken first; then the same credit note keyed again without the two values, and the book restored again. Never use Accept As Is. No other company may be loaded.

The two previous sets keyed this credit note without (W23, `lab/1342-w23-answers`) and with (W24, `lab/1342-w24-answers`) its original invoice number `BP/26-27/0001` and date 1 Aug 2026, and read it with one wide request that fetches 14 named fields: the two answers are byte-identical and neither value occurs anywhere in them, so those reads do not show where Tally stores the two values, or whether it does. This set asks for the whole voucher object instead, and compares the object of the note keyed with the values against the object of the note keyed without them, leaf by leaf, by program.

**What is new in this set** (nothing else is): two requests that return every method of the credit note voucher instead of 14 named ones, and the program that compares two answers leaf by leaf. Both requests are the wide request of W23 (`w23-wide-credit-note-0921.xml`, unchanged here) with only its field list replaced, and each is a NEW SHAPE: no answer to either has been captured, so its size and content are bounded below, not known. `w26-whole-credit-note-0921.xml` has `<NATIVEMETHOD>*</NATIVEMETHOD>` where the wide request has its `<FETCH>` list; `w26-whole-credit-note-fetchstar-0921.xml` has `<FETCH>*</FETCH>` there, and is sent only under the rule in step 6. A third shape of the same question, the single-object export (`TYPE` Object, `SUBTYPE` Voucher), is not used: its identifier for a voucher has not been measured. The program is `tools/leaf-compare.ps1` (SHA-256 in `SHA256.txt`), checked in step 3 against two answers that are already committed. Everything else (the voucher keyed, the screens, the backup and restore, the marks, the empty-day check) is W24's, and the answers of W23, W24 and W25 are known.

**Writes, by kind:** one backup file written (outside the book); two vouchers saved, each of type `Credit Note` on 21 Sep 2026 (one in step 5, one in step 8), never both in the book at once; two restores of the company with Replace of its data folder (steps 7 and 10). The operator creates or alters no master, imports and exports nothing, and changes no company feature. Every other request is a read. The series is not read in this set (W24 and W25 measured that the save leaves the type's series row unchanged).
