# Windows item 628-C0b v1: a second copy of one supplier invoice, an optional copy, a cancelled copy, a Journal and a Payment to the same supplier, keyed on Tally's screen, then read three ways to learn what a check for an invoice already in the books can see. (26 Oct 2026.) SYNTHETIC ONLY: THE COMPANY is `BRIDGE GST LEDGER LAB`, the company GS1-L1 created (its GUID as GS1-L1 step 1 recorded it). Runs only after item 628-C0 has closed, in the same sitting or a later one; a FINDING in C0 does not stop this item, a STOP in C0 does. LAB-COMMON v3 applies in full; where an item and LAB-COMMON differ, the stricter holds. No ComplyEaze Bridge program is used.

Why: issue 1904 asks ComplyEaze Bridge to refuse a purchase whose supplier invoice is already in the books, so input tax credit is never claimed twice. Its design reads a supplier's vouchers for a whole year and compares the supplier's invoice reference, the voucher number and the bill names. Bridge's voucher read today asks for every field of every ledger entry, which costs about 64,000 bytes a voucher on the captured Purchase; a year of a large book would not fit. This item answers, on vouchers typed on Tally's own screen: (1) whether a narrower read, naming only the ledger-entry fields and the bill allocations, returns the same answer as Bridge's own read; (2) whether a Journal and a Payment carry the supplier invoice reference and the party; (3) what an optional and a cancelled copy keep; (4) whether the voucher's party GSTIN is filled on a keyed voucher; (5) what Tally 7.2 shows when a second copy of a supplier invoice number is keyed (protocol reference §9.19 records that Tally saved one, but its screen was read only after the save, so whether it warned is not recorded; this was item C2's question in issue 628's sequence). §9.19 also records that a keyed Purchase's bill allocation exported with an amount and no name; this item reads the bill allocations three ways to see which read carries the name. It also records each read's bytes per voucher.

Any difference, or a ratio under two = FINDING of the first rank; record the lines whole.
