## Why this sheet exists
#1633 asks whether an export from a GST return moves the company's voucher mark `ALTVCHID` and whether the next voucher then skips that rise, because a native post is checked against the marks before and after it. `lab/1633-export-ready-answers` measured it for a GSTR-1 JSON export on TallyPrime 7.2: each of two exports raised the voucher mark by 3 with no voucher's `alter_id` moving, and the next voucher took the id after the rise. Opening GSTR-1 moved nothing. Whether the same holds for another return is not measured. This sheet runs one GSTR-3B export on the same book, with the marks and the vouchers' ids read before and after, then keys one more voucher. It decides nothing about posting.
