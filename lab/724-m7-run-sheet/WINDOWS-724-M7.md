## What changed since v1.0 (for whoever knows the old sheet)
- `masters` voucher_types: every row whose series method is "automatic" now also carries "sub_method" ("auto_retain" or "auto_renumber"; an object {"unrecognised": ...} or "absent" otherwise). v0's comparison with #1542's answers allows exactly that added key.
- A second refusal code, import_voucher_numbering_not_retain, for an Automatic type that is not on Auto Retain. New steps v5r (at build) and v4r (at post).
- A Journal that carries its own voucher number is now under the rule. New steps v1n and v2n (both expect a BUILT file, which is never imported or posted).
- "Automatic (Manual Override)" is printed as method "automatic_manual_override".
- N2 is backed up before its first step and RESTORED at the end, so the book is left as found (v1.0 left a fourth Journal in it).
