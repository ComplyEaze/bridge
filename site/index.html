Download for Claude Desktop

Windows x64 and Apple Silicon Macs · Claude Desktop extensionNot yet code-signed; your computer may warn you.

A thick case file, rendered in 3D and pinned through eight short chapters. It arrives with twenty-six sticky index flags down its edge, coloured by the kind of finding. Asked who owes money for more than 90 days, the flags fold back into the edge, it opens to an ageing page, and the five overdue parties are ringed in pencil. The page turns to a voucher, two pencil ticks are drawn, and its 40A(3) flag leaves the page and lands as row 1 of a working paper titled “Working paper · Tax audit FY 2025-26” (scrutiny is in progress, not yet released). The page turns again to a bank statement; a slip lifts off each of five rows and the pile reads 139 ready, and three question-mark flags mark near-miss ledger names that wait for your decision; you decide them one after another, each turns into a tick, and the count of ready vouchers, the voucher file ComplyEaze Bridge prepares for you to import in Tally, rises from 139 to 142. A replica of the real ComplyEaze Bridge approval dialog rises from one row, asks you to post that one voucher, and shrinks back into the row with a red tick: one voucher per approval. After you import the prepared file in Tally yourself, each voucher is ticked as ComplyEaze Bridge reads it back, counting up to 142 of 142. A narrow receipt slip slides out for the calls made. Finally the flags retract, the file shuts on one tick, and the four install steps and the download follow.

Set it up in four steps.

  1. In TallyPrime, turn on the HTTP gateway (Tally acts as “Both”).
  2. Open the downloaded .mcpb file. If Claude Desktop doesn't pick it up: Settings → Extensions → Advanced settings → Install Extension.
  3. Check the Tally port in the extension settings (usually 9000).
  4. Save, restart Claude Desktop if the tools don't appear, and ask about your books in plain language.
