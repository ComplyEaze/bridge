- `list_companies` lists every open company even when one company's name cannot be sent in a read. Such a name is blank, holds a control character, or is longer than 360 UTF-8 bytes. Before, that one name refused the whole list. Now the company is listed with `name_refusal` saying why, its name is shown whole with control and text-direction characters escaped, and only that company's reads are refused, as `company_name_invalid`. Company names are kept exactly as Tally reports them, without trimming, so a name with leading or trailing spaces is now shown and stored with them. Names of up to 360 bytes are accepted, up from 255, including when a Schedule III grouping decision is recorded. A bidirectional control in a shown name is written as its code (#2433).
