- `sales_register`, `purchase_register` and `gst_by_counter_ledger` now read a window whose vouchers Tally stored with foreign-currency amounts, instead of refusing it (#683). Each amount is read at its rupee figure, with the foreign amount apart, as `vouchers` reads it, and a ledger set aside for its currency is classified by its master, so `register_ledger_currency_excluded` is no longer given. A voucher whose amounts still cannot be read is listed in `withheld_vouchers`, counted in `withheld_total`, and the window is `partial` (`gst_by_counter_ledger` then refuses as `gst_by_ledger_window_partial`). Shown in tests on Tally's answers from one synthetic book on TallyPrime 7.2 Silver, one day of eleven vouchers; not yet run against a live Tally.
