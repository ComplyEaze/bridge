# Lab run sheet: an abandoned statement build's file imported into Tally by hand with posting off, then the rebuild posted; what `verify_import`, the transfers section and `local_data_report` say, and whether a duplicate is booked (#1738, the case that parked S1). SYNTHETIC COMPANY ONLY. Not for merge

About 90 minutes. `LAB-COMMON.md` in this folder (v3, a byte copy from `lab/2018-stock-query-with-item`, sha256 `5370c6d288cd0f54a4ac547c513ec1648dd8bec0ea5a327d46b0de519a6369c6`) applies in full; where this sheet and it differ, the stricter holds. Every call is a built tool; no XML request is sent by curl (GET /status as C2 c and C10). THIS SHEET WRITES TO THE BOOK, twice: X1's file is imported by hand through Tally's own Import menu (launch 1, posting off), and X2 is posted through `post_import` with the person's approval (launch 2, posting on). The book is backed up first (S0) and restored at the end (C5, C6).

**WHAT IT DECIDES.** #1738's route S1 is parked until one lab sheet runs the case that parked it (#1738, decision of 29 Oct 2026; the earlier run, `lab/1738-s1-abandon-rebuild-answers`, covered an abandoned build that was never imported). Here the abandoned build X1 is **imported into Tally by hand** while ComplyEaze Bridge's posting is off, so ComplyEaze Bridge's journal says X1 was never sent, and then the same statement is built again as X2 and posted:
1. what `verify_import` says of X1 after the hand import (`posted_verified`, `verification_incomplete` or `not_found` for its vouchers);
2. what the transfers section and the step texts say after the hand import (the other account's skip of the shared rows), and whether they send the person to rebuild (the route #1821 closed: a rebuild is offered only when every voucher of the batch was `not_found` and no file was imported);
3. whether the tool admits the rebuild X2 at all, and whether its approval box says anything of the vouchers already in the book;
4. **whether posting X2 books a duplicate**: how many Contras the book holds for 3 and 4 August after the post.
It decides no design. The results are evidence for a later design, with a confidence marker.

STOP RULES: C7 and C8 of LAB-COMMON; any dialog not named; a second company or `tally.exe`; a call that sends X1 (a `dispatch` other than `not_dispatched` for X1); a hand-import counter other than two created; V or M not as predicted at any check without a step that explains it; the restore not returning the marks; an exe sha256 that is not the one named; Ctrl+Q or Escape at the Gateway (an incident: if a prompt shows, press no key, take a screenshot and STOP).

**PASS (the sheet ran)** = every step done and every call answered and kept, X1 never sent by the tool, the hand import created exactly two vouchers, the restore returned the marks and an empty August. **FAIL** = a send of X1, a call that failed recorded as a result, a book that is not restored, or a voucher in August after the restore.

**THE FINDING** (recorded for #1738, with a confidence marker, by a later change): what `verify_import` and `local_data_report` say of a batch whose file was imported by hand; what the transfers section and its step sentences tell the person; whether the tool admits the rebuild and its approval box warns; and whether posting the rebuild books a duplicate.
